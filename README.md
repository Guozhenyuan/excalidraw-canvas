# 私有画布 · Excalidraw

[打开网站](https://guozhenyuan.github.io/excalidraw-canvas/)

GitHub Pages 托管编辑器，另一个私有 GitHub 仓库保存 `.excalidraw` 文件。每张画布有固定链接，修改停止约 3 秒后自动保存。没有多人实时协作；每次成功保存生成一个 Git 提交。

## Data Viz 素材库

已内置 32 个可编辑图表素材。连接并打开或新建画布后，点击顶部「素材库」，在 Excalidraw 素材面板中选取图表并放到画布上；插入的元素通过原有自动保存流程写入你的私有图稿。素材不会自动插入或覆盖当前画布。

素材随网站部署，首次加载无需访问第三方素材站。每次打开网页会加载内置素材，重复打开素材库不会重复添加，也不会替换当前页面已有的其他素材。当前页面中对素材库自身的增删不单独同步到 GitHub；已插入画布的图形会随图稿保存。网络失败时可点「重试素材库」。

## 自动同步

连接后默认开启。页面可见时每 30 秒检查 GitHub 的目录和当前画布；切回页面或网络恢复时也会检查，并保留最少请求间隔。菜单中的「自动同步 GitHub」可关闭自动保存和远端检查，开关仅作用于当前页面；「立即同步」仍可手动检查并保存当前修改。新建或导入画布仍需先选择保存位置。

- 本地修改停止约 3 秒后上传。其他窗口或设备保存的版本，在当前画布没有未保存修改时自动载入，保留当前视角。
- 本地与远端都有修改时暂停同步，不做自动合并或覆盖；可以另存副本，或备份后点「读取远端版本」。远端删除或改名时同样保留页面内容，不会自动重建旧文件。
- 检查途中继续绘图、切换文件、保存或退出连接时，会重新核对状态；旧响应不会覆盖新操作。绘图手势或文字编辑期间延后载入。
- 只读画布也会自动读取更新。关闭页面后不运行同步，也不提供多人实时协作。
- 未变化的目录使用 ETag 条件请求。读取网络错误会退避重试，尊重服务器限流等待时间；权限、登录或保存冲突会明确提示处理。上传失败仍保留页面内容，请按提示重试保存。
- 菜单展示最近检查时间，底部显示同步异常。首次在 Notion 内使用仍受浏览器存储分区及登录限制影响。

## 首次连接（一次设置，记住当前浏览器）

1. 打开网站，点「连接 GitHub」。点「在 GitHub 创建连接凭据」，名称、不过期（No expiration）和 Contents 读写权限已预填。若 GitHub 组织策略要求有效期，则以其要求为准。
2. 在 GitHub 的 Repository access 选择 **Only select repositories**，仅勾选 **excalidraw-drawings**。确认 Contents 为 **Read and write**；Metadata 只读自动附带。不要授予所有仓库或额外权限。
3. 点 Generate token，将生成的凭据复制到本站密码框。不要发送到聊天、Notion 正文、网址或 GitHub 文件中。
4. 勾选「在此浏览器长期保留连接（直到主动退出）」，点「连接并打开画布」。这会将凭据存入本机 IndexedDB，不设置本站的自动失效时间，直到主动退出或网站数据被清除；未勾选则只在当前页面内存使用。它是浏览器记住访问凭据，不是 GitHub OAuth/服务端登录会话。
5. 下次在同一浏览器、同一存储分区打开画布，会自动连接并加载。换设备、清除数据、凭据过期或浏览器限制存储时需要重新连接。GitHub 拒绝过期凭据后会尝试清除本机记录。

旧版仍留在浏览器中的 30 天连接记录会自动迁移为长期保留，每次恢复仍由 GitHub 验证凭据。此设置不会延长 GitHub 凭据本身的有效期；已有凭据如设置过 30 天有效期，需在 GitHub 重新创建不过期凭据，并在本站退出后重新连接。GitHub 仍可能撤销凭据（例如长期未使用），浏览器也可能清理网站数据，因而无法保证永不需要重新连接。

GitHub 本身的网页登录状态不能直接授权任意静态网站读取私有仓库。首次设置仍然需要上述 GitHub 访问凭据；日常无需反复输入。

## 日常使用

- 菜单 ☰ → 选择 GitHub 保存目录 → 输入画布名称 →「新建画布」。使用你填写的名称，只补全 `.excalidraw` 后缀，不再追加随机字符。
- 菜单按 GitHub 实际目录显示画布，包含根目录、子目录和只有其他文件的目录。可刷新目录，也可粘贴当前仓库和分支的 GitHub 文件或目录链接定位。
- 选择上级目录 →「＋ 新建目录」→ 输入名称 →「创建并选中」。支持中文和 `项目/草稿` 这样的多级名称；创建成功后自动选中新目录。已有目录直接选中，同名文件会提示换名。只读链接不显示创建入口。
- 为让尚无图稿的目录在刷新后仍然存在，网站会在新目录中保存一个空的 `.gitkeep` 文件。该文件不会显示为画布，也不会覆盖已有文件；首次保存画布前目录已真实写入 GitHub。
- 打开画布链接只显示画布、名称、同步状态与简短提示，管理操作收在菜单中。
- 停止修改约 3 秒自动保存；保存进行中仍可继续绘图，之后的修改会保留为待保存状态并继续同步。
- 等顶部显示「已同步 GitHub」再离开。失败会暂停自动保存并显示重试/备份按钮，不会静默覆盖远端版本。页面关闭前未完成的保存不保证送达。
- 新文件名、导入图稿或更改另存路径不会直接触发自动覆盖；首次手动保存成功后才启用该文件的自动保存。
- 「复制链接」可放入 Notion Embed。链接包含文件路径及必要的仓库/分支信息，不含凭据或图稿内容。
- 菜单 → 选择目录、填写文件名 →「保存到所选位置」：保存前预览完整路径；成功后自动保存到新位置，原文件保留。同名图稿会提示改名或先打开，不自动覆盖。
- 选择目录和修改另存文件名不会停止当前画布的自动保存，也不会被自动保存重置。顶部「保存」始终保存当前画布；导入后需先选择位置完成首次保存。
- 保存响应丢失时核对远端是否为刚刚提交的完整内容；完全一致才认定成功。稍后重试会先核对未确认的保存，不盲目覆盖其他修改。真正冲突可「另存副本」保留当前内容。
- 每个文件旁可「重命名」或「删除」。重命名可同时选择其他目录；同名目标不会被覆盖。当前画布若有未保存修改，会先保存，再更名，并更新页面地址。旧画布链接会失效，请重新复制链接并更新 Notion 嵌入。
- 删除需要再次确认具体文件。删除当前画布后，页面保留内容供备份或另存，并停止自动保存，不会自动重新创建文件。删除记录保留在 GitHub 提交历史中；本站尚未提供回收站或一键恢复功能。
- 重命名和删除通过单次 Git 提交更新目录，保留其他文件；操作核对文件版本，分支更新不使用强制覆盖。若其他窗口已修改文件，会中止并提示重新核对。只读链接隐藏这些管理操作。
- 菜单 → 账户与连接 →「退出并清除连接」会清除本机连接并清空当前页面画布。若浏览器阻止清除，会明确提示需要手动清除网站数据。

## 隐私与访问范围

图稿保存在私有仓库，拥有链接本身不授予查看/修改权限。当前版本依赖你提供的 GitHub 仓库访问权限，不是服务器端的独立账户系统。

选择记住后，凭据保存在本机浏览器中，可被有权限的同源脚本、浏览器扩展或能使用此浏览器的人访问；它不是加密保险箱，也不是 HttpOnly 会话。保护该 GitHub Pages 域下所有站点的写权限，不要在共享/不可信浏览器中记住连接。公开源码和构建产物不包含真实凭据。

图稿不自动存入本机持久缓存，GitHub 是持久保存位置。字体/脚本随站点发布；浏览器请求只允许本站及 GitHub API。图内外部 iframe 被禁用。支持中文路径、图内图片和最多 20 MB 图稿。

更强的登录体验可升级为 GitHub App + 服务端会话：服务端保管凭据、按用户鉴权，并处理刷新。它需要额外后端及 App 注册，当前版本尚未实现。

## Notion Embed

在 Notion 输入 `/embed`，粘贴对应画布的固定 HTTPS 链接。链接形式为 `?file=文件夹/画布.excalidraw`；访问者仍需自己的 GitHub 权限。

浏览器允许时可以直接编辑并自动保存。Notion iframe 与独立窗口可能使用不同的浏览器存储分区；独立窗口记住连接不保证 iframe 同时连接。如果嵌入不允许存储，则只能本次连接或使用独立窗口。剪贴板、下载、确认弹窗也可能受宿主限制。Notion 官方提示需要外站登录的嵌入在桌面和移动客户端存在限制，需逐客户端实测。

本站未设置禁止被嵌入的 X-Frame-Options 或 CSP frame-ancestors。HTML 的 `frame-src 'none'` 禁止画布内部嵌入外站，不禁止 Notion 嵌入本站。`frame-ancestors` 只能用 HTTP 响应头，不能写在 meta 中；GitHub Pages 不提供项目级任意自定义响应头配置。

## 构建与部署

Node.js 22+：`npm ci`、`npm test`、`npm run build`。GitHub Settings → Pages → Source 选择 GitHub Actions；main 推送后自动构建部署。

构建仅使用前端仓库 GITHUB_TOKEN，不读取私有图稿，不需要配置图稿令牌到 Actions Secrets。源码和图稿仓库保持分离。代码使用文件 SHA 检测保存冲突，并按不可变 blob SHA 读取图稿。
